## 測定方法（範囲を先に言う）

- **対象26社**（下表）＋ 比較対象として `yamato-final.vercel.app` を同条件で測定
- Playwright / Chromium / **1440×900px** / 日本語ロケール / UA=Mac Chrome
- 全高までスクロールして遅延読み込みを起こし、**フルページ1枚**を撮影
- あわせて DOM から実測：節の切り出し（全幅85%以上・高さ120px以上のブロック）、
  節ごとの高さ・リンク数・画像数・文字数・左右分割の有無・同幅カードグリッドの有無・バナー数
- **DNS到達不可**：木下工務店(.net)、オープンハウス・アーキテクト、住友不動産（→木下は.co.jpで再取得）
- **取得失敗**：ミサワホーム（1画面0節＝スプラッシュで止まった）→ 集計から除外

**この数字が見ている範囲**：PC 1440px のトップページ1枚だけ。SP版・下層ページは見ていない。

## 2.5 全252節を型に分類した結果（サブエージェント実測・分類率99.6%）

**この節は2度書き換えている。(c)→(d-2) の順に読むこと。結論は (d-2)。**

### (a) 最強の単一事実 ― 「一節＝一画面」

節分解が健全な21社に限って本文節を数えると（n=197）:

| 指標 | Q1 | 中央値 | Q3 |
|---|---|---|---|
| 節の高さ（画面） | 0.58 | **0.81** | 1.07 |
| 節のリンク数 | 2 | **5** | 11 |
| 節の文字数 | 39 | **140** | 299 |

社ごとの「本文節1つ＝何画面か」は **Q1 1.03 ／ 中央値 1.10 ／ Q3 1.19**。
**四分位範囲がわずか0.16画面**。26社が例外なく守っている唯一の規範がこれ。
やまとは **1.24画面**。とくに #11 奈良 3.80／#3 信条 2.42／#8 モデルハウス 2.12 が規範外。

### (b) 「読ませる散文の節」は、26社が揃って避けている

**400字以上かつリンク5本以下の節は、252節中わずか2節（0.8%）。**
しかもうち1件は災害見舞い文で設計ではない。意図的な例は秀光ビルド『家づくり8つの正直宣言』1件だけ。

やまとは **18節中3節**がこれに該当（信条 531字/0本、分譲地 404字/1本、家づくりの流れ 442字/1本）。

### (c) DOM上は、グリッドとバナー並びが同じ構造に見える

- grid検出53節のうち **32節（60%）が同時に banners≥3**
- banners≥3 の節は **23/26社（88%）**が持つ
- **つまり「バナー」とは画像＋短文＋リンクのカードが3枚以上並ぶ形のこと**であって、
  必ずしもキャンペーン告知の見た目のことではない

三菱地所ホームの LINEUP（3枚並び）も、この分類では banner-row と同じ構造に落ちる。
**ただしDOM上同じ構造だからといって、同じ部品として採用してよいわけではない。→ (d-2)**

**3列 vs 4列の使い分けは文字量で決まる**：

| | 節数 | 高さ中央値 | リンク中央値 | **文字中央値** |
|---|---|---|---|---|
| 3列 | 24 | 0.87画面 | 5.5 | **212字** |
| 4列 | 13 | 0.69画面 | 10.0 | **46字** |

**3列＝1〜2行の説明つき。4列＝説明を捨ててラベルだけ。** 説明を残すなら3列。

### (d) 【訂正】左右分割の回数 ― DOM実測は大きく取りこぼしていた

**初版で「左右分割は句読点。使う社の85%が1ページ1回だけ。やまとの5節は突出」と書いたが、これは誤り。**

DOM の `split` 検出器は「直下の子で幅が親の28〜72%かつ縦が重なるもの」しか見ない。
grid や absolute で組まれた左右分割は原理的に見えない。**測定範囲と欠陥の所在がずれていた**（既知の再発パターン）。

全景を1社ずつ目視した結果：

| 社 | 左右分割の回数 | 反転 |
|---|---|---|
| ウィザースホーム | **11連続** | 反転なし（テキスト常に左） |
| 三菱地所ホーム | **7回**（ABOUT US 3連続・WORKS 3連続・RECRUIT） | **交互反転あり** |
| 木下工務店 | **6回**（OUR SERVICE 3連続） | **交互反転あり** |
| 土屋ホーム | 5回 | 1箇所だけ反転 |
| アイ工務店 | 4回 | 一部反転 |
| クレバリーホーム | 3連続 | 反転なし（写真常に左） |
| アキュラホーム | ABOUTカード6枚 | カード内で上下段が交互 |
| ヤマダホームズ／ユニバーサルホーム | 各2回 | 反転なし |
| アエラホーム／富士住建／一建設／桧家住宅／アイフルホーム | **0回** | — |

**やまとの5節は突出していない。** 6社が3回以上使っており、最多は11連続。
**交互反転も26社中1社ではなく5社**（三菱地所・木下・アキュラ・アイ工務店・土屋）。
`lu-band--flip` は業界的にごく普通。

**では左右分割は使ってよいのか** ― 条件付きで可。唯一の実証研究がある。

**Kim Flaherty / Nielsen Norman Group / 2017-11-26**
[Zigzag Image–Text Layouts Make Scanning Less Efficient](https://www.nngroup.com/articles/zigzag-page-layout/)
（アイトラッキング・各条件30〜35名・4サイト／日本語版は U-Site 2018-06-27）

- **装飾画像**を交互配置すると "users stumble"（流し読みが躓く）
- **情報価値のある画像なら、ジグザグでも整列でも差はない**
- 推奨：装飾画像は縦に整列させる／レイアウト都合だけで画像を使わない

**やまとの帯写真は実際の商品外観＝情報価値がある。** この研究では減点対象にならない。

### (d-2) 【訂正】バナーについて ― 僕の途中の訂正が行き過ぎだった

初版「バナーは採らない」→ 中盤「グリッドとバナーは同一物だから採る」と訂正したが、
**中盤の訂正が誤り**。3本目の調査で分かれた：

**バナー並びは大組織の産物であって、日本的美意識の産物ではない。**
HTML中の `bnr|banner` の出現数を実測：

| 社 | banner語 |
|---|---|
| 一条工務店 | **159** |
| アキュラホーム | **24** |
| URBAN HOME / クラシスホーム / neie | 1〜2 |
| SHIN KA / コン工務店 / Re Loop | **0** |
| ジブンハウス / アイフルホーム（全景目視） | **0枚** |

一条のマークアップは `banner-list-1 / -2 / -3` ＋ `banner-item-caption` ×11 という
**番号付きの反復スロット**＝編集者が中身を入れ替える容器。

さらに **トライベック株式会社 / 2018-02-19**
[「このバナーを特に目立たせたい」編](https://www.tribeck.jp/column/opinion/marketing/20180219/)：

> 「個々のバナーを主張したデザインにしてしまうと、隣り合うバナー同士で干渉しあってしまい、
> 結果としてどのバナーも目立たなくなる」
> 「ひとつでも例外を作ってしまうと、それが"定常化"して……崩壊させる引き金となり」

**バナーが並ぶ状態は設計判断の結果ではなく、運用要望の累積の結果。**

しかも「バナーで回遊率が上がる」の一次的裏付けは**存在しない**。
回遊率を論じる4社（TETORI／awoo／マテリアルデジタル／エフ・コード）で改善策にバナーを挙げた社はゼロ。
そもそも回遊率の定義が4社で割れている。

**結論：カードグリッド（商品を3枚並べる）は26社全社が持つ普遍的な部品。採る。
バナー並び（キャンペーン画像の積層）は組織規模の産物。やまとには要らない。**

### (e) FVの次は「理念」ではなく「一覧」

- **19/26社（73%）**が 900〜1800px 帯（＝2画面目）に
  お知らせ／イベント か バナー並びを置く
- バナー初出：**69%が2画面以内、81%が3画面以内**
- やまとの最初の出口は **5.5画面目**

全リンクに占めるヘッダー＋フッターの比率は中央値26%。住宅情報館は**ヘッダー1節にリンク156本**で、
除外すると 42.94 → 12.15 に落ちる。
やまとのヘッダー＋フッター比率は16%と低いので、**除外しても最下位は動かない**（実質2.7本/画面）。

### (g) 26社は二つの学派に分かれる ― うちは「余白型」で正しい

全景を1社ずつ精読すると、密度の作り方が2つに割れる。

| | 余白型 | 密集型 |
|---|---|---|
| 社 | 土屋ホーム／東栄住宅／ウィザースホーム／ユニバーサルホーム／スウェーデンハウス | 日本ハウスHD／ヤマト住建／ロイヤルハウス／ポラス／タマホーム |
| 節間の余白 | 画面の半分〜1画面 | ほぼゼロ（タイルが密着） |
| 地色 | 1〜2色に絞り、**余白そのもので節を切る** | 白／薄グレーの**交代だけ**で節を切る |
| 1節の行き先 | **1〜4本** | 6〜9本 |
| バナー・タイル総数 | 4〜5枚 | **26〜35枚超** |
| 見出しの下の本文 | 2〜5行 | **ゼロ**（見出し＋罫線ですぐタイル） |

**やまとの美学は明確に余白型。** 密集型を真似る必要はない。
しかし**余白型の5社ですら、次の3つは全社が持っている**：

1. **どの節にも最低1本の出口。** ウィザースホームは左右分割を11連続でやるが、
   **11節すべてに緑のボタンが1本ずつ**入っている。**出口ゼロの節は1つも無い**
2. **ヒーロー直後のピックアップ行**（土屋4枚／ユニバーサル5枚／ウィザース3枚／スウェーデン カルーセル）
3. **カルーセル。** 「1/15」「1/10」「1/8」の総枚数表示が土屋・秀光・ヤマダ・スウェーデン・東栄に共通。
   **見えているのは3〜5枚で、裏にさらに5〜15枚ある**

**③が決定的。カルーセルは「縦を伸ばさずに密度を上げる」唯一の装置。**
うちは密度を上げようとすると縦に伸ばすしかなかった。

### (h) 三菱地所ホームは、うちの双子だった

26社で2番目に長いのが三菱地所ホーム。骨格を並べると**ほぼ同じ**。

| | 三菱地所ホーム | やまと |
|---|---|---|
| ページ全高 | 18.94画面 | 21.43画面 |
| 節数 | 16〜17 | 18 |
| 1節の高さ | 1.00〜1.18画面 | 1.24画面 |
| 左右分割 | **7回**（3連続×2） | 5節 |
| 交互反転 | **あり** | あり（京） |
| 見出し下の本文 | **3〜4行（26社中最長）** | 同程度 |
| 明朝・広い余白・上質な写真 | ○ | ○ |
| **1画面あたりリンク** | **14.89本** | **3.22本** |

**長さも、節数も、左右分割も、交互反転も、本文の長さも、書体も余白も、ほぼ同じ。
違うのは出口の数だけで、そこに4.6倍の差がある。**

三菱地所ホームが何をしているか：

1. **どのブロックにも必ず黒い丸ボタンが1つ**（「詳細を見る」「ツーバイネクスト構法」）

3. **WORKS / OWNER'S VOICES / コラムがすべてタブ＋カード＋一覧ボタン**
4. **赤いCTA 2本を、ページ中盤と最下部の2箇所に同じ形で再掲**

**やまとに足りないのは「型」ではなく「扉」。**

## 3. 「機能性が高い」の正体 ― 移せる部品

上の (a)〜(h) を踏まえて、競合が使っていてうちが使っていない部品。

### ① カードグリッド（同幅を横に3〜4）＝「並べて選ばせる」型

商品ラインナップの扱いが決定的に違う。

| 社 | 商品数 | 置き方 | おおよその高さ |
|---|---|---|---|
| 三菱地所ホーム | 3×3カテゴリ | **3列 × 3段** | 各段 0.35画面 |
| 一条工務店 | 4 | **4列** | 0.4画面 |
| クレバリーホーム | 4 | **4列** | 0.35画面 |
| アイフルホーム | 2 | **2列** | 0.3画面 |
| 土屋ホーム | 2 | 縦積み（写真フルブリード） | 2つで 0.75画面 |
| **やまと** | **3** | **縦積み（写真半分＋紙葉半分）** | **3つで 2.2画面** |

**三菱地所ホームが重要**。明朝・広い余白・上質な写真という、うちと同じ register の会社が、
LINEUP を **3列カードグリッド**で組んでいる。カード＝写真＋商品名＋3行の説明＋外部リンクアイコン。
**「横に並べる＝安っぽい」は成り立っていない。**

### ② 機能ナビ（FV直下のアイコン付き近道）

スウェーデンハウスは FV の直下に **4つのアイコン付きボタン**を置く：
建築実例／商品ラインアップ／土地・分譲住宅／北欧住宅の性能。

読者が「読む」前に「行ける」。うちは FV の次が実績帯（リンク0）→信条（リンク0）で、
**最初の出口が現れるのは5.5画面目**。

### ③ 日付つきリスト（お知らせ・イベント・実例）＝「更新されている証拠」

スウェーデンハウス・日本ハウスHD・一建設・秀光ビルドはいずれも下層に
**日付＋1行見出し＋一覧を見る**のリストを持つ。1行ごとにリンク。
これが link/画面 を押し上げている実体であり、同時に「生きているサイト」の証明になっている。

### ④ 施工事例のブロック ― やまとのTOPに1つも無い ★新規

B2C注文住宅10社を実測したところ、**8社が施工事例を上位1/3に置いている**（アイ工務店1番目、
クラシスホーム2番目、コン工務店2番目、SHIN KA 3番目、ハイブリッドホーム3番目、
アキュラホーム4番目、URBAN HOME 4番目、一条工務店5番目）。

そして **お客様の声が施工事例より上に来た例はゼロ**。
**家づくりの流れが上位に来た例もゼロ**（最下部か下層のみ）。

| ブロック | 定石の位置 | やまとの現状 |
|---|---|---|
| 施工事例・建築実例 | **上位1/3**（10社中8社） | **TOPに存在しない** |

## 4. うちに移せる具体形（結論）

**三菱地所ホームとの差は「型」ではなく「扉」だった。**
骨格（長さ・節数・左右分割・交互反転・本文の長さ・明朝・余白）はほぼ同じで、
違うのは出口が **14.89本/画面 対 3.22本/画面** であること。

順に効く手：

1. **どの節にも出口を1本。** いま出口ゼロは4節。
   とくに #3 信条（2.42画面）と #11 奈良（3.80画面）＝**ページの29%**
2. **ラインナップを3列カードに。** 3つで 2.2画面 → **0.65画面**（図面 案A・実測）
3. **施工事例ブロックを上位に新設。** 10社中8社が上位1/3に置く。**やまとには1つも無い**
4. **来場予約を上にも置く。** 10社中10社が上下2回。やまとは下のみ
5. **カルーセルを1つ導入。**「1/15」型。縦を伸ばさずに密度を上げる唯一の装置
6. **FV直下に機能ナビ4本。** 最初の出口を 5.5画面目 → 1画面目へ

**やらないこと**
- バナー並び（キャンペーン画像の積層）＝ 組織規模の産物。一次的な効果の裏付けも無い
- 左右分割をやめること ＝ **やめる理由が無かった**。NN/g の条件（装飾画像）に当たらない
- 密集型を真似ること ＝ やまとは余白型で、そちらが正しい
