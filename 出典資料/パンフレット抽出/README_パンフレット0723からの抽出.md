## 🎯 このパンフレットが示す設計上の答え

**パンフレットの比較表には、家の外観写真が1枚も出てこない。**
プランを分けているのは **設備の製品写真** と **シリーズカラー** だけ。

→ 「どの外観をどのプランに当てるか」という問題が、**そもそも発生しない構成**になっている。
→ **京に外観写真が無い**という事実も、この構成なら問題にならない。
→ 設備の製品写真はメーカー支給なので、**全セルに必ず存在し、光と背景が揃っている**。

### ただしサイトに丸ごと持ってくるときの注意

**パンフレットは、既に話をしている相手に手渡すもの。サイトは、まだ何も知らない人から最初の問い合わせを取るもの。**

3列に並べると、冷たい初読の人には
「京はトイレが手洗いだけ」「風はキッチンが1種類（花は3種類）」が**数として見える**。
パンフレットが成立するのは、隣に営業がいるから。

→ **借りるもの:** シリーズカラー／設備の製品写真という語彙／下段の共通ブロック／静かな組版
→ **借りないもの:** 3列を横に数えられる比較グリッド

これは既存方針（トヨタ・レクサスは装備の有無の3列表をサイト本体に置かない）と同じ結論。
