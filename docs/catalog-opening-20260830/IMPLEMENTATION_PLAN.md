# カタログ表紙オープニング 実装計画

## 目的

ページを開いた瞬間に、深紅の和紙から金の牡丹と二羽の燕が立ち上がり、既存の表紙正本へ静かに収まる。生成映像を主役にせず、最終的な形・配置・文字は正本表紙とHTMLを唯一の基準にする。

## 制作方式

- 本番方式: 正本表紙の燕を使った決定論的な順方向合成。逆再生は使用しない。
- PC: 16:9、1920×1080、5.708秒、H.264、24fps、無音
- SP: 9:16、1080×1920、5.708秒、H.264、24fps、無音
- 本番素材: `cover-opening-desktop-v2.mp4` / `cover-opening-mobile-v2.mp4`
- 再現スクリプト: `build-v2-composite.sh`
- Higgsfieldの順再生POCはPC/SP各45 credits、合計90 creditsを使用したが、燕が欠けるため本番不採用。
- POC job: PC `f8165aeb-6fab-481a-b4e7-cbf49810b146` / SP `847c5db7-6c99-4e0d-8439-f12d907337ec`

## 破綻防止の設計

1. 正本表紙から二羽を透過素材として抽出し、生成モデルに鳥の形を描かせない。
2. 上の燕は嘴が左を向いたまま右から左へ、下の燕は嘴が右を向いたまま左から右へ進める。
3. 二羽は開始から終了まで完全に画面内へ収め、端から欠けた状態を作らない。
4. 花と燕を別レイヤーにし、途中で融合・増殖・変形しないようにする。
5. 4.08秒から正本表紙へクロスフェードし、4.50秒以降は正本の形と配置だけを見せる。
6. タイトル・ブランド表記は映像へ焼き込まず、生きたHTMLで4.15秒から表示する。
7. 動画終了後は動画を透明化し、直下の正本表紙画像を表示する。
8. autoplay失敗・読込失敗・reduced-motionでは、正本表紙へ即時フォールバックする。

## 時間設計

- 0.00–0.70秒: 深紅の和紙。中央の型押しだけが静かに見える。
- 0.70–3.10秒: 金の牡丹線が静かに現れる。
- 0.90–4.00秒: 完全な二羽が別々の順方向軌道で定位置へ滑空する。
- 4.08–4.50秒: 正本表紙へクロスフェードする。
- 4.15–5.05秒: HTMLタイトル「やまとの家／花鳥風月」が静かに現れる。
- 4.50–5.70秒: 正本表紙を保持する。

## 品質ゲート

- 燕は常に二羽。画面端で欠けず、増殖・融合・液状化がない。
- 頭、翼、二股の尾が各フレームで読める。
- 嘴の向きと進行方向が一致し、逆再生の羽ばたきや尾から進む動きがない。
- 牡丹の線が途中で文字や別の植物へ変形しない。
- カメラ移動、ズーム、不要な粒子、花びら、音声を入れない。
- PC/SPとも最終フレームは既存表紙と一致させる。
- スキップ、ページ送り、縦スクロール、本編遷移を妨げない。

## 実装・QA結果

- 実装済み: PCは `cover-opening-desktop-v2.mp4`、SPは `cover-opening-mobile-v2.mp4` を読み分ける。
- 終端保証: 動画終了後は正本表紙へ置換され、生成映像の最終形を残さない。
- 表示確認: 1440 / 1024 / 768 / 390px の4幅で、横はみ出しなし・終端の表紙配置一致を確認。PCは1440/1024、SPは768/390でV2を選択。
- 再生確認: 自動再生、4.15秒のタイトル表示、終了時の静止画切替にエラーなし。
- 動作確認: PC/SPの10フレーム比較で、上の燕は左向きに左へ、下の燕は右向きに右へ進み、全フレームで二羽を分離。
- 操作確認: 再生中でも次ページへ移動でき、前ページへ戻るとオープニングを再演する。
- スクロール確認: ホイール操作でカタログを飛ばして次セクションへ進め、スクロールロックなし。
- 代替動作: `prefers-reduced-motion` では動画を再生せず、正本表紙とタイトルを即時表示。
- ブラウザ確認: 4幅の静止終端ではコンソール・ページ・通信エラー0件。実再生検査で表紙V2動画の通信失敗0件。
- 目視記録: `docs/catalog-opening-20260830/qa-v2/` にPC/SP連続フレーム、4幅終端、実再生状態を保存。
