# コピーの統合方針

新しい売り文句は作らない。TOPの「土地・設計・施工の自社一貫体制」「商品ラインナップ」「施工事例」「奈良から大阪への通勤」「モデルハウス見学」を採用。最新B案・FV原文は保持する。

Atlasの列車種別、平日夕方の一例、起終点、駅前後の移動を含まない説明と時刻出典を保持。生成の模型風案内には「イラスト」を維持。施工例写真までの時間とはしない。

下層ページは承認済みプレビューの文言を引き継ぐ。ただし「現在の本番は変更していません」「現行ページと比較する」という切替後に誤りになる制作説明は削除・修正。フォーム未接続・保証と仕様の確認事項を、接続済み／確定済みと書き換えない。

価格・保証・仕様の新たな確定はこのリリースに含めない。旧スキル内の旧価格・古いFVコピーを採用しない。コピーの最終表示はPC/SPの統合後に点検する。
