# 写真差し替えの自己レビュー

visual-qa-codex / design-critic-codexによる creator self-review。前回の採用方針を把握した担当者による確認であり、独立評価ではない。

PC1440・1024・768、SP390・320のChromium、およびWebKit1440・390で対象画像を確認した。全7条件で画像decode成功、横はみ出しなし。PC/SPのカードと施工写真を原寸画面で再目視。

施工は二人・資料・作業台が一緒に残り、「設計内容を現場で確認」という見出しとの対応が従来の上を見る姿より明確。図面・電卓・筆記する手元、分譲地と前面道路、近鉄と朱雀門も各カード内に残る。G1のキッチンは保持。色を過剰に合わせず、原画の自然な色調を維持する。

3:2の共通画像枠でカードの高さが揃う。横レールの右側に次カードが一部見えるのは既存の導線で、ページ全体の横あふれではない。見出し・本文・矢印に被りなし。画像内部の拡大を解除したため、ホバーや通常モーションでも手元・電車が切れない。

PDF由来の原寸限界は残るが、現在のカード表示では内容を判読でき、拡大生成で細部を捏造していない。原画取り寄せは将来の鮮明さ改善として記録し、今回の画像内容の改善と分ける。
