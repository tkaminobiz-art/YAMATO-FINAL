# 視覚確認

全32項目を1440×1000、390×844で実描画し、8枚の一覧画像で全項目の構成を確認。320×844・1024×768も32項目の表示、文字寸法、画像、横はみ出しを測定。全幅とも本文/表16px以上、補助14px以上、見出しPC42px/SP28pxを基本とする。重要条件は16pxの通常表示で、隠れた詳細へ追いやらない。

P07は左の導入・選択条件、右の支給空間写真、下の4機能を実写/原図で構成。P28は明色の比較表とシリーズの文字・色、SPは項目ごとの3行。P26は初期10年→有償延長2回の帯と、保証対象の説明図。原採用6画像の紙色・深紅・金の細罫・誌面構成を実文字へ置換。写真・製品の精密形状は生成見本から転載していない。

見出しはShippori Mincho B1、本文/表はZen Kaku Gothic Newの実フォント。元の表紙には指定書体のロードがなくフォールバックが使われていたため、新しいフォントはカタログ内部用の別名でローカル読み込み。4WOFF2合計487600 bytes。表紙のフォント解決を変えず、内容側でFontFaceSetのロード成功を確認した。

表紙articleのSHAは開始時と一致。元CSS・4画像・2動画のSHAも一致。静止表紙の透明度遷移を完了して同状態撮影し、PCは全画素一致。SPは既存ページカウンターの総数20→33が表紙下端に2px重なる領域で16画素のみ変化。表紙本体の絵・位置・書体・色は不変更。全画面一律0差分とは報告しない。

発見・修正：固定ヘッダーに章番号が隠れるため、閲覧状態だけヘッダー高を余白へ反映。拡大終了のフォーカスはhistory復帰後に戻す。単独シリーズの価格は横帯にまとめ、京/風の色を対応付け。指定フォントの未ロードを検出して中身専用のローカルフォントに修正。

限界：実機ではなくChromium/WebKitでの画面・操作検証。色チップ、CAD、実解析動画の原本は未取得。色は名称で案内し、292/303px間取りは原寸以下の参考図。大きく精密な図面に見せていない。

自己レビュー：比較対象は採用済みP07/P28/P26のPC/SP6画面と開始時カタログ。紙色・細罫・明朝見出しを引き継ぎ、写真のある設備説明、シリーズ比較、保証の条件を同じ読み順へ揃えた。本文を縮めて固定高へ押し込む状態を解消した一方、長い項目は縦スクロールが必要。色柄ページは正規色チップ未取得のため色名中心で、見本の視覚的な比較には届いていない。これは技術テストで解消したと扱わず、正規素材入手後の改善点とする。実フォント確定後の一覧画像でも改行・余白・写真切り取りを再確認した。
